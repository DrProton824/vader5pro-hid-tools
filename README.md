# Flydigi Vader 5 Pro Remapper

A lightweight, portable remapper for the extra buttons on the Vader 5 Pro
that Windows applications cannot see through XInput.

## What it does

Maps the vendor-only buttons (M1–M4, LM/RM, C/Z, Home, Arrow, Circle)
to any keyboard shortcut you choose.  The standard gamepad buttons
(A/B/X/Y, bumpers, triggers, sticks, d-pad) are left untouched.

## What it does NOT do

Replace Flydigi Space Station.  It solves exactly one problem and nothing else.

## Usage

1. Extract the folder anywhere.
2. Run **VaderService.exe** in the background. A tray icon appears
   (system tray, near the clock – click the `^` arrow if it's hidden).
   Right-click it for **Open Config** / **Exit**.
3. Run **VaderConfig.exe** to change mappings (or use the tray menu).
4. Close VaderConfig when done – VaderService picks up changes automatically.

Only one copy of each executable can run at a time. Launching
VaderService.exe while it's already running just shows a message box
pointing you at the existing tray icon instead of starting a second copy.

## Portable

Everything lives in one folder.  Deleting it completely removes the application.
Nothing is written to AppData, the registry, or anywhere else.

## Optional: Start with Windows

Create a shortcut to VaderService.exe and place it in:

    %APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup

## Building from source

    pip install pyinstaller hid pillow
    python tools/generate_icons.py   # one-time: creates assets/icons/*.ico
    python build/build.py

`build.py` will generate the icons automatically on first run if you skip
the manual step above.

## v1.1 changes

A few things were broken or missing in the first pass; fixed/added here:

- **Buttons weren't being captured.** The Vader 5 Pro exposes multiple HID
  interfaces under the same VID/PID (an XInput-passthrough one and the
  vendor-specific one that actually reports M1–M4/LM/RM/C/Z/Home/Arrow/Circle).
  The old code opened *a* device by VID/PID and got whichever interface the
  OS listed first – usually the wrong one, so it opened fine but never saw
  button events. It also had the wrong VID/PID (`0x04B4:0x2412`) instead of
  the one the reverse-engineering tools actually used (`0x37D7:0x2401`).
  Both are fixed: `hid_reader.py` now enumerates all interfaces for the
  VID/PID and opens the one on usage page `0xFFA0` specifically.
- **No tray icon.** VaderService now shows a system tray icon with
  "Open Config" / "Exit", implemented with plain ctypes (`src/shared/tray.py`)
  to avoid adding a dependency.
- **Multiple copies could run at once.** Both executables now grab a named
  Win32 mutex on startup (`src/shared/single_instance.py`); a second launch
  shows a message box and exits instead of running alongside the first.
- **Generic PyInstaller icon.** Both exes now build with a custom icon
  (`assets/icons/service.ico` / `config.ico`, generated by
  `tools/generate_icons.py`).
- **Tkinter looked like Tkinter.** The config GUI's native title bar is
  stripped via ctypes and replaced with a custom-drawn one (app icon, title,
  minimize, close, drag-to-move) so it reads as a normal Windows app rather
  than a bare Tk window, while keeping the taskbar entry and Alt-Tab
  behaviour of a regular window.
